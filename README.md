MINI PROJECT 8
"ELECTRICITY BILL PREDICTION USING MLFLOW"
PROJECT OVER VIEW:
     This project predicts electricity bills using machine learning algorithms and tracks model experiments using MLflow.
     It compares three regression models to identify the best-performing model.
OBJECTIVES:
     Predict electricity bills based on electricity consumption and household information.
     Train and compare multiple machine learning models.
     Track model parameters and evaluation metrics using MLflow.
     Save the best-performing model for future predictions.
